Trait Lower 

pub trait Lower<C>: Sized
where
    C: ?Sized,
{
    type Runtime;

    // Required method
    fn lower(self, context: &mut C) -> Result<Self::Runtime, Report>;
}
Expand description

Lower an instruction using the capabilities supplied by a program loader.

Instruction authors express required capabilities as bounds on C in their implementation. Unchanged dialect instructions receive identity lowering.
