Expand description

Write a value in the source spelling accepted by its Parse implementation.

Implementations must round-trip: parsing the printed text yields a value equal to self. When no such spelling exists, return fmt::Error rather than writing text that would parse differently.

fmt::Formatter implements fmt::Write, so a Display impl can forward to print.
