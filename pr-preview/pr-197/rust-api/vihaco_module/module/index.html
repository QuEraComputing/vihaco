Constants§

DEFAULT_MAX_CALL_DEPTH
The default limit on nested call frames (the entry function’s frame included) for the standard runtimes: the stdlib ExecutionState and the CPU. A call that would exceed it fails, naming the callee, instead of recursing until memory runs out.
MAX_LOCALS
The largest number of local slots, parameters included, a function may declare. ProgramMetadata::validate enforces it, and runtime frame entry re-checks it before allocating, since modules can also be built directly.
