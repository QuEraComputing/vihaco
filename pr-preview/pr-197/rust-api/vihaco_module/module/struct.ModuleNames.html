Struct ModuleNames 

Source 
pub struct ModuleNames<'a, Ty> { /* private fields */ }
Expand description

A read-only view of a module’s name-bearing tables.

Built by LocalModule::names or ProgramMetadata::names. Every lookup tolerates bad indices (an unvalidated module), returning None rather than panicking, so messages about broken modules can still be rendered.
