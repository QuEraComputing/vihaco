Struct StepError 

Source 
pub struct StepError { /* private fields */ }
Expand description

An instruction failed while executing a program.

Like an eyre context layer, it displays only where the failure happened: the location and the instruction, at @main+2 (address 2) cpu::cpu::get_field @Point.x``. What went wrong is its source, so {:#} (or walking eyre::Report::chain) shows both, once each: at @main+2 (address 2) cpu::cpu::get_field @Point.x: type error: heap object (slot 1, generation 1) is struct Pair, expected struct Point.

The source is the step’s own error (for example a device’s error type), except that a bare [HeapError] appears as a [NamedHeapError], rendered with the module’s names; its error is the structured HeapError. A heap error under a device’s wrap_err context is left as it is, so the context stays in the chain. StepError::error returns the step’s error unchanged. downcast_ref on the returned report itself finds the StepError: search the chain for the cause.
