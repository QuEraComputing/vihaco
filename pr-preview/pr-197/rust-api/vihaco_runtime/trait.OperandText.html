Expand description

How a syntax operand type writes the runtime value it lowers to, in source syntax.

Self is the operand’s syntax type (the T in a pattern’s $0:T), and Runtime the instruction field it lowers to. For example the CPU’s FieldOperand writes a runtime FieldSlot as @Point.y, or 0, 1 when the struct has no name. Operands whose syntax type has no impl fall back to the runtime value’s Display; an operand with neither is a compile error at the instruction’s derive.
