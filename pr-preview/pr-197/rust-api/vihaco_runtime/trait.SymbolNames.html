Expand description

Names for instruction operands: types (through TypeNames), struct fields, functions, labels and strings.

Every method defaults to “no name”, so an operand renders in its numeric source form. vihaco-module implements this for modules and program metadata.

Provided Methods§

fn field_name(&self, struct_id: u32, field: u32) -> Option<&str>

The name of field field of struct struct_id.

fn function_name(&self, function: u32) -> Option<&str>

The name of function function, without the leading @.

fn function_starting_at(&self, address: u32) -> Option<u32>

The function whose first instruction is at address (the first such entry in table order, as a direct call resolves it).

fn label_at(&self, address: u32) -> Option<&str>

The name of a label at address, without the leading @.

fn string(&self, index: u32) -> Option<&str>

String-table entry index.

fn write_call_target( &self, address: u32, f: &mut Formatter<'_>, ) -> Result<(), Error>

A call target at address, as a call resolves it: @name of the function starting there, else the address itself.

fn write_jump_target( &self, address: u32, f: &mut Formatter<'_>, ) -> Result<(), Error>

A jump target at address, as a jump resolves it: @name of a label there, else the address itself. Never a function name, which a jump cannot name, even when the address is a function’s first instruction.

fn write_function( &self, function: u32, f: &mut Formatter<'_>, ) -> Result<(), Error>

Function function (a function reference), as @name, else its index.
