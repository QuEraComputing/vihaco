Expand description

A value that can live in the constant pool of a standard header.

.const str "text" and .const fn @name are assembled through string and function; a value model without string or function constants returns None and such directives are rejected. string_index and function_index report the table references of a value, so that a hand-written index such as .const str 3 is rejected and tools can explain constants.
