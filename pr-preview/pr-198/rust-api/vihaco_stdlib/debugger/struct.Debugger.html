Struct Debugger 

Source 
pub struct Debugger<K: Ord + 'static, I> { /* private fields */ }
Expand description

A component that manages breakpoints.

This component can handle both explicit breakpoints (those appearing in source) and “gutter” breakpoints, or those that are inserted (similar to gdb’s INT3 insertion on b).
