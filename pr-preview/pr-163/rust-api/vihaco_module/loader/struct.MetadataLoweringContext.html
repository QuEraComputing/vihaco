Struct MetadataLoweringContext 

Source 
pub struct MetadataLoweringContext { /* private fields */ }
Expand description

Symbol lookups backed by explicit, immutable program metadata.

Function indices retain metadata table order, independently of executable addresses. String lookups never append to or reorder the supplied table. The context is independent of any instruction set; dialect crates provide implementations of their lowering-capability traits for it.
