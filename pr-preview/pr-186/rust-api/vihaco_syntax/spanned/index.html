Module spanned 

Source
Expand description

Located, error-recovering parsers for .text streams and header declarations.

parse_text and parse_declarations accept exactly the inputs that ParsedModule::parse_section and HeaderDeclarations accept, but keep the byte span of every instruction, symbol definition, and declaration, and keep going after a malformed item so that every problem is reported as a human-readable SyntaxError.

Spans are byte ranges relative to the parsed block. Recovery is line-based in .text (a malformed item skips the rest of its line) and ;-based in headers (a malformed declaration skips to its terminator).
