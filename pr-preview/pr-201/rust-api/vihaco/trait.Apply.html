Trait Apply 

Source 
pub trait Apply<E> {
    type Effect;
    type Error;

    // Required method
    fn apply(&mut self, effect: E) -> Result<Self::Effect, Self::Error>;
}
Expand description

Handle an effect at its destination and return the next effect.

Use () for a terminal handler and std::convert::Infallible for an infallible handler. The caller or route chooses the next destination.

Required Associated Types§

Source

type Effect

The effect emitted after successful application.

Source

type Error

The failure reported by this destination.

Required Methods§

Source

fn apply(&mut self, effect: E) -> Result<Self::Effect, Self::Error>

Apply the effect and return the next value in the chain.

§Errors

Returns the destination’s validation or application error. Mutations already made by this handler or previous handlers are retained.

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
