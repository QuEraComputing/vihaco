Struct, named-type, and type operands for the struct, array, wrap, and unwrap instructions, and their lowering.

Structs are written by name (struct_new @Point, get_field @Point.y) or by struct-table index (struct_new 0, get_field 0, 1). Named types are written the same way (wrap @location, wrap 0). Array element types are ordinary types, where a struct or named type may also be named: array_new struct @Point, 4, array_get type @location, and so may the types in a call_indirect signature: call_indirect (struct @Point) -> u64. Every form is resolved against the section’s struct table through StructLookup and its named-type table through NamedTypeLookup when the program is lowered, so the StructLayout, FieldSlot, named-type index, and element [Type] stored in the runtime instruction always agree with the tables. The CPU then checks each heap object against them at runtime.

Structs§

FunctionTypeOperand
A function type as written in source, (struct @Point, type @location) -> u64: a [FunctionType] whose parameter and result types may name structs and named types, as a TypeOperand does. Numeric forms (struct 0, type 0) are accepted too. Lowering resolves every name and checks every reference against the tables.
