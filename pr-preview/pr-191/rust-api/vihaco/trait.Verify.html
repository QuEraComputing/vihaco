Expand description

The typing rule for one instruction.

Instruction authors express the capabilities they need (operand types, local types, signatures, struct layouts, component-specific state) as bounds on C.

Required Methods§

fn verify(&self, context: &mut C) -> Result<(), Report>

Check this instruction’s inputs against the abstract state in context and update the state to the instruction’s post-state.

Provided Methods§

fn flow(&self) -> Flow

Where control goes after this instruction.

This must depend only on the instruction’s operands, never on abstract state, so that block boundaries and reachability do not depend on whether any rule succeeds. Most instructions continue to the next address; control-flow instructions override this.

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
