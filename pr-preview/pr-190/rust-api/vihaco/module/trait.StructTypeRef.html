Expand description

Exposes the table references carried by a type, so module assembly can check Type::Struct indices against the struct table and Type::Named indices against the named-type table, and check named-type representations.

Required Methods§

Source

fn visit_struct_refs(&self, visit: &mut dyn FnMut(u32))

Visit every struct-table index this type refers to, including ones nested inside compound types such as array element types.

Provided Methods§

Source

fn visit_named_refs(&self, visit: &mut dyn FnMut(u32))

Visit every named-type-table index this type refers to, including ones nested inside compound types. Type models without named types keep the default, which visits nothing.

Source

fn is_named_type_repr(&self) -> bool

Whether this type may represent a named type (a scalar word type). Type models without named types keep the default, false, so their named-type tables must be empty.
