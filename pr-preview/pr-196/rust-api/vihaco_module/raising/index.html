Module raising 

Source
Expand description

Raising a loaded module back to source: the name lookups instructions use to Raise themselves, and the standard header rebuilt from the module’s tables.

Raising is the inverse of lowering. Where lowering resolved @name operands to addresses and indices and interned string literals, raising looks the names and the text up again. The capability traits mirror the lowering ones (LabelNames for LabelLookup, FunctionNames for FunctionLookup, StringTable for StringIntern), so dialect Raise implementations stay generic over the context. RaiseContext implements all three for a loaded LocalModule.
