Trait Raise 

pub trait Raise<C>
where
    C: ?Sized,
{
    type Syntax;

    // Required method
    fn raise(&self, context: &C) -> Result<Self::Syntax, Report>;
}
Expand description

Raise a runtime instruction back to its source syntax: the inverse of Lower.

A disassembler raises each loaded instruction with a context that names what lowering resolved: symbols for addresses, functions for indices, and text for string-table indices. Instruction authors express the lookups they need as bounds on C, mirroring their Lower bounds. A raise only looks names up; it never invents one, and it fails if the runtime form has no source spelling that lowers back to it. Unchanged dialect instructions receive identity raising.

For every instruction i that raising accepts, lowering i.raise(context)? in a matching loader yields i again.
